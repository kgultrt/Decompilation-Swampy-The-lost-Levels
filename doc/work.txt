游戏的6种流体类型:
水 毒水 泥巴 泥浆 蒸汽 混凝土
(以下简称 F1 F2 F3 F4 F5 F6)
特性:
F1 + F2 = F2
F1 + F3 = F3
F1 + F4 = 相互抵消
F1 + F6 = F6

F2 + F3 = F3
F2 + F4 = 爆炸
F2 + F6 = F6

F3 + F5 = 湿润F3
F3 + F4 = 相互抵消
F6 + F5 = 湿润F6
F6 + F4 = 相互抵消

F3 拥有干燥度，经过一段时间会变成泥土
F4 会腐蚀泥土
F5 会往上升
F6 拥有干燥度，经过一段时间会变成石头

#FFFFFFFF - 空白
#FFFFEA00 - 标识浴缸/过关room
#FF474747 - 石头
#FFA6A6A6 - 浅色石头
#FF282828 - 深色石头
#FF715B31 - 泥土 (用来凿的)
#FF8B1987 - 毒水
#FFBE652F - 泥浆
#FFB20815 - 木炭
#FF3F321B - 泥巴 (液体)
